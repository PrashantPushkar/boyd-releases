# BOYD by Hridaan Labs

**Brain On Your Device.**

[Download the Windows 0.7.1 preview](https://github.com/PrashantPushkar/boyd-releases/releases/download/v0.7.1/BOYD-0.7.1-win-x64.zip) · [Release notes](https://github.com/PrashantPushkar/boyd-releases/releases/tag/v0.7.1) · [Product page](https://hridaanlabs.com/boyd)

This public repository distributes BOYD preview packages, SHA-256 checksums and signed update metadata. The development repository and all personal data are separate. The downloadable JavaScript application is readable as part of the installed runtime; publishing this distribution repository does not grant an open-source licence to the original BOYD application. Third-party components retain their bundled licences.

Includes a small local CPU model/runtime. No account or API key required. Offline is the default; optional public information checks do not upload prompts or documents. AI can make mistakes. The Windows x64 preview and separate Android research preview are not validated teachers or fully offline copies of Anukul/Ekalavya. An iPhone build is not available. Application files are not Windows code-signed.

Extract the ZIP outside synced folders and read README.md before starting. Export existing records before moving versions. Inspect release.json for signed package metadata; use the pinned public key in the installed engine to verify it.
